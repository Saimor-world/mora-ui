# Universe Experience Reset

Status: implementation contract. The current planet-dashboard composition is a discarded prototype.

## Product purpose

Universe is neither another dashboard nor a file browser wearing a space skin. It answers:

1. What constitutes this organisation?
2. Where is attention or movement now?
3. Why are things connected, and what can I do about it?

Home is the personal day surface. Finder is the exhaustive hierarchy. Universe is the shared organisational situation model.

## One field, two lenses

Organisation and Zusammenhänge must preserve identical geometry, camera and selection.

Organisation shows department identity, mandate, known people, measured operational state, truthful content counts and verified attention signals.

Zusammenhänge lets structure recede while evidence-backed relations become legible. Every relation has a source, explanation and action. Missing evidence is an honest empty state.

The switch changes the lens, never the scene.

## Mycelium contract

Mycelium is not a visual style. It is the evidence graph between organisational objects.

An edge may exist only through:
- explicit hierarchy or ownership
- a stored reference
- a task, decision or incident targeting both objects
- a verified signal assigned to an object
- a relation explicitly created by a person

Forbidden evidence:
- similar document/folder counts
- spatial proximity or matching colours
- random affinity
- an unstored AI guess

Every edge exposes relation type, source, freshness and its available next action.

## Spatial model

- No mandatory Saimôr hub in the centre.
- Departments are stable territories, not glowing planets.
- Contents live inside or immediately around their territory.
- Signals arrive at a boundary and remain distinct from structure.
- Selection opens a contextual workbench; other territories recede.
- Click/tap is primary. Hover is optional enhancement.
- Empty space supports orientation instead of becoming unused canvas.

## Interface hierarchy

Persistent: organisation identity, Home/Universe, the two lenses, command access and Môra.

Universe-only: scene orientation, territory field, selected-context inspector, source/freshness state and an optional collapsed event stream.

Remove from Universe:
- WidgetGrid and permanent dashboard cards
- centre logo as navigation hub
- always-on beams
- redundant search/audio controls
- a second full-screen SpatialMindfield world

Those capabilities remain available through Home, Dock or context actions.

## Truth model

Every metric is marked internally as:
- live
- cached, with timestamp
- derived, with named inputs
- missing
- example, only in an explicit demo tenant

Unknown never becomes zero. Missing health never becomes 98%. Document quantity never becomes organisational health.

## Interaction

1. Enter to a calm, unselected overview.
2. Select a territory; do not auto-fly.
3. Inspector explains identity, current state, missing connections and actions.
4. Switch lens while position and selection remain stable.
5. Select evidence; inspector changes to its source and meaning.
6. Open a workspace only by explicit action.
7. Escape clears evidence, then territory, then returns Home.

## Visual direction

A brighter controlled atmosphere, low-chroma background, colour reserved for territories and evidence, no glass-card wallpaper, readable typography, collision-free labels, and motion only for meaningful state changes.

## Target components

- UniverseView: orchestration and lens state
- OrganizationField: shared geometry/camera
- DepartmentTerritory: accessible organisational object
- EvidenceLayer: evidence-backed Mycelium
- UniverseInspector: context and actions
- UniverseSourceStatus: live/cached/missing provenance

Retire from Universe composition:
- WidgetGrid
- centre-core connections
- SpatialMindfield as alternate scene
- Planet as primary department representation
- metric-similarity edges

## Delivery

A. Shared field, remove widgets/hub, replace planets, preserve access/navigation.
B. Data-quality types, remove fabricated defaults, evidence-only relations.
C. Context work: open, ask Môra, create task/decision, keyboard/touch.
D. Responsive and motion finish plus live visual regression captures.

## Acceptance

- Both lenses are recognisably the same place.
- No green cross or permanent beam exists.
- No Universe dashboard wallpaper remains.
- No fabricated health/activity default is visible.
- Every relation explains itself.
- Selection works without hover.
- Users can explain Home vs Organisation vs Zusammenhänge.
- Saimôr HQ displays real gaps honestly.
