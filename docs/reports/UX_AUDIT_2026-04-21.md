# SAIMOR OS UX Audit - 2026-04-21

Scope: Local Truth OS surface in `INTERFACE`, with `CORE` running on `127.0.0.1:8081` and UI on `127.0.0.1:3000`.

## Success Criteria

- Entry path proves usable UI, not only HTTP 200.
- Primary OS panes have clear empty, loading, and degraded states.
- German UI is consistent in Local Truth mode.
- Finder, audio, and app shell feel intentional rather than generic dark glass.
- Verification includes typecheck, lint, build, local health, and at least one real browser probe.

## Findings

| ID | Severity | Area | Finding | Acceptance Criterion |
| --- | --- | --- | --- | --- |
| UX-001 | P0 | Entry | `/login` is only a redirect spinner, so health checks can pass while the usable surface is not ready. | Browser gate waits for actionable Welcome UI or `/home`, not just `/login` 200. |
| UX-002 | P0 | Entry | Root loading state is visually anonymous and gives no recovery route if session detection stalls. | Loading screen shows what is being checked and reveals a fallback action. |
| UX-003 | P1 | Finder | Finder had stronger data logic than visual hierarchy; folder/file cards looked too flat. | Cards expose context, depth, and primary actions without visual monotony. |
| UX-004 | P1 | Audio | Music depended on uploaded tracks; zero-track state felt broken. | Built-in ambient fallback can be started from Dock and Settings. |
| UX-005 | P1 | Users | Users app mixes English and German labels. | Visible labels, filters, toasts, and modal copy are German. |
| UX-006 | P1 | Users | Empty team/user list says only "No members found" without a next step. | Empty state explains cause and offers invite/action. |
| UX-007 | P1 | Team | Team room uses English metadata (`Shared channel`, `members`, `Team member`). | Team UI uses German role/channel labels. |
| UX-008 | P1 | Team | Empty team/activity states are too passive. | Empty states explain the next useful action. |
| UX-009 | P1 | Scanner | Empty intake state is icon + "Noch keine Dateien"; no instruction. | Empty state explains drop/upload flow and system routing value. |
| UX-010 | P1 | Settings | Visible "Zukuenftige Features" block reads like unfinished product. | Replace with current capabilities / operational notes or hide. |
| UX-011 | P2 | Quick Preview | Dynamic Tailwind classes (`bg-${color}`) are not guaranteed to compile. | Use explicit class maps. |
| UX-012 | P2 | Quick Preview | Missing preview states do not tell the user what can be done next. | Preview empty states explain why and offer full-open path where possible. |
| UX-013 | P2 | Timeline | MindLoop empty/loading states are minimal and include mojibake. | States are legible German and explain observation behavior. |
| UX-014 | P2 | Launcher | Port owner PID `0` can produce a misleading "unexpected process" warning. | Ignore non-positive owner PIDs before warning/stopping. |
| UX-015 | P2 | App Loader | Generic skeleton did not carry SAIMOR identity. | Loader shows branded, spatial loading state. |
| UX-016 | P2 | Glass Material | Many panes use similar dark glass with low depth. | Core glass panels include subtle active/inactive material gradients. |
