# SAIMÔR Next — Visual Migration Guardrails

This branch is not a redesign-away from SAIMÔR. It is a reduction of accumulated visual layers.

## Keep

- cosmic depth and spatial identity
- MÔRA as a living presence, not a chatbot mascot
- emerald / violet / gold as semantic signals
- Universe as an explicit spatial exploration mode
- glass as material where depth is useful
- slow ambient motion in the background

## Remove from the daily path

- permanent app inventory in the Dock
- glow used as generic decoration
- purple tint on every surface
- repeated card grids that look like SaaS dashboards
- long interaction transitions on ordinary controls
- visual competition between shell, window chrome and app content

## New hierarchy

1. **Home = Command Field** — one place to orient, ask MÔRA and enter the four operating surfaces.
2. **Work** — projects, tasks, files and products.
3. **Capital** — wallets, assets and programmable capital. Observation first.
4. **MÔRA** — intelligence, context and memory across every surface.
5. **Systems** — runtime, Nightwatch and infrastructure.
6. **Universe** — spatial exploration, retained as a signature mode rather than the default navigation model.

## Safety rule for Capital

The initial XRPL path is read-only. No seed phrase, private key or signing path belongs in the UI or repository. Live execution must be introduced later through explicit policy + approval + receipt flows.
